# 猪体重计算优化说明

## 优化内容

### 1. 体重计算公式优化
- **原问题**: 计算出的体重异常，不符合实际数据中2.5-3.78kg的范围
- **优化方案**: 重新设计体重估算公式，针对您数据集中的猪体重分布进行调整

### 2. 新的体重计算公式
```python
# 线性公式：重量(kg) = base_weight + length_factor * (长度 - threshold)
estimated_weight = base_weight + length_factor * max(0, length_cm - 30)
```

### 3. 三种计算模式
- **standard**: 标准模式，基础体重2.5kg，适合大多数情况
- **young_pig**: 保守估算，倾向于较低体重（2.3kg基础）
- **medium_pig**: 积极估算，倾向于较高体重（2.7kg基础）

## 测试结果

### 不同长度猪的体重估算
- **30cm猪**: 2.50kg (范围: 2.20-2.80kg)
- **35cm猪**: 2.67kg (范围: 2.35-2.99kg) 
- **40cm猪**: 2.86kg (范围: 2.51-3.20kg)

### 体重范围控制
- 仅确保体重为正值（最小0.5kg）
- 针对2.5-3.78kg范围优化，但不限制上限
- 可适应不同体型的猪

## 优化特点

1. **精确匹配**: 针对2.5-3.78kg体重范围优化
2. **多种模式**: 提供三种不同的估算策略

## 注意事项

- 体重计算基于猪的长度测量
- 需要检测到尺子或底座作为参考对象
- 公式适用于幼猪到中等体型的猪
- 实际使用时建议根据具体数据进一步微调参数
