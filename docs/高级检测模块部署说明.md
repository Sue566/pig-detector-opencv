# 高级猪检测模块部署说明

## 🎯 概述

全新的模块化高级猪检测系统，采用清晰的目录结构，提供精确的长度测量、重量估算和高级可视化功能。

## 🏗️ 目录结构

```
pig-detector-opencv/
├── advanced_detection/                 # 高级检测模块
│   ├── __init__.py                    # 模块初始化
│   ├── core/                          # 核心功能
│   │   ├── __init__.py
│   │   ├── config.py                  # 配置和常量定义
│   │   ├── detector.py                # 主检测器类
│   │   └── measurement.py             # 测量计算模块
│   ├── visualization/                 # 可视化模块
│   │   ├── __init__.py
│   │   └── renderer.py                # 高级渲染器
│   └── api/                          # API接口模块
│       ├── __init__.py
│       └── endpoints.py               # FastAPI端点定义
├── scripts/
│   └── api.py                        # 主API文件（已集成）
└── test_advanced_detection_complete.py # 完整测试文件
```

## 🎨 颜色配置

### 明确的颜色定义
- **🔴 猪**: 红色 `RGB(255, 0, 0)` / `#FF0000`
- **🔵 尺子**: 蓝色 `RGB(0, 100, 255)` / `#0064FF`  
- **🟢 底座**: 绿色 `RGB(0, 200, 0)` / `#00C800`

### 长度标注
- **📏 标注线**: 黄色 `RGB(255, 255, 0)`
- **🎯 箭头**: 指示测量方向
- **📊 精度**: 小数点后1位

## ✨ 核心功能

### 1. 精确测量 (`measurement.py`)
- ✅ 基于尺子的长度计算（默认30cm）
- ✅ 基于底座的长度计算（默认60×40cm）
- ✅ 智能选择最佳参考物体
- ✅ 改进的重量估算算法
- ✅ 重量范围计算（±20%）

### 2. 高级可视化 (`renderer.py`)
- ✅ 不同颜色的检测框
- ✅ 详细的测量信息标注
- ✅ 长度标注线和箭头
- ✅ 多行文本显示
- ✅ 测量结果摘要图片

### 3. 智能检测器 (`detector.py`)
- ✅ 坐标格式自动识别和转换
- ✅ 综合测量结果计算
- ✅ 检测统计信息
- ✅ 完整的处理流程

### 4. API集成 (`endpoints.py`)
- ✅ `/api/predict_advanced` - 完整高级检测
- ✅ `/api/calculate_measurements_only` - 仅测量计算
- ✅ 支持Minio和本地存储
- ✅ 灵活的参数配置

## 📋 API接口

### 高级检测接口
**端点**: `POST /api/predict_advanced`

**请求参数**:
```json
{
    "image_path": "图片URL或路径",
    "conf": 0.5,
    "top_k": 10,
    "return_visualization": true,
    "return_summary": false,
    "ruler_length_cm": 30.0,
    "base_length_cm": 60.0,
    "base_width_cm": 40.0
}
```

**响应格式**:
```json
{
    "code": 200,
    "msg": "高级检测成功",
    "data": {
        "type": "advanced_detection",
        "detections": [
            {
                "class_id": 0,
                "confidence": 0.95,
                "box": [x1, y1, x2, y2],
                "width_px": 200,
                "height_px": 300
            }
        ],
        "measurements": {
            "length_cm": 85.5,
            "weight_kg": 45.2,
            "weight_range_kg": [36.2, 54.2],
            "calculation_method": "基于尺子(30cm)",
            "reference_object": "ruler",
            "confidence": "high"
        },
        "statistics": {
            "total_detections": 2,
            "pig_count": 1,
            "ruler_count": 1,
            "base_count": 0,
            "avg_confidence": 0.915
        },
        "image_info": {
            "width": 1920,
            "height": 1080,
            "source": "图片路径"
        },
        "result_image_url": "可视化图片URL",
        "summary_image_url": "摘要图片URL"
    }
}
```

### 仅测量接口
**端点**: `POST /api/calculate_measurements_only`

返回测量结果，不生成可视化图片，响应更快。

## 🔧 配置说明

### 测量参数配置
在 `advanced_detection/core/config.py` 中可调整：

```python
MEASUREMENT_CONFIG = {
    "ruler": {
        "default_length_cm": 30.0,    # 默认尺子长度
        "min_length_cm": 10.0,
        "max_length_cm": 100.0
    },
    "base": {
        "default_length_cm": 60.0,    # 默认底座长度
        "default_width_cm": 40.0,     # 默认底座宽度
    },
    "weight": {
        "formula_coefficient": 0.002,  # 重量公式系数
        "formula_exponent": 2.5,       # 重量公式指数
        "range_percentage": 0.2        # 重量范围百分比
    }
}
```

### 可视化配置
```python
VISUALIZATION_CONFIG = {
    "box": {
        "line_width": 3,              # 边框线宽

        "line_height": 22,            # 行高

    }
```

```python
LENGTH_ANNOTATION_CONFIG = {
```
