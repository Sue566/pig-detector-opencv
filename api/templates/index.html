🔌 API接口说明

GET /

根路径 - 自动重定向到本页面

GET /docs

Swagger API交互式文档界面

GET /api/health

健康检查 - 获取服务状态和版本信息

POST /api/predict

完整检测与测量 - 返回JSON格式的检测结果和测量数据

POST /api/predict_image

图像检测 - 直接返回可视化图片文件

⚙️ 技术规格

🏗️ 系统架构

  • FastAPI + Uvicorn
  • YOLOv8 深度学习模型
  • OpenCV 图像处理
  • MinIO 对象存储

📊 检测类别

  • 类别0: Pig (猪)
  • 类别1: Ruler (尺子)
  • 类别2: Base/Scale (底座)
  • 支持多目标同时检测

📐 测量原理

  • 尺子参考: 30cm标准长度
  • 底座参考: 60x40cm标准尺寸
  • 重量公式: 0.002 × 长度²·⁵
  • 误差范围: ±20%

🔧 环境要求

  • Python 3.8+
  • CUDA支持(可选)
  • 8GB+ 内存推荐
  • 网络访问权限
